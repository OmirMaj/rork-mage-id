At true icon sizes (16–24px) the crane reads as busy motion, so the plan is: animate at the big sizes (splash, the "Ask MAGE" header, AI loading/"thinking" states, onboarding) and use a clean static end-frame (the finished "AI" + spark, or just the spark) for tiny inline icons.

How this ships: this preview uses SVG/SMIL so it loops in your browser. In the app, react-native-svg can't run SMIL, so I'd rebuild the exact same motion with react-native-reanimated (a small <MageBuildAnimation /> component) for the animated surfaces, plus a static MageIntelligence end-frame for icons.
