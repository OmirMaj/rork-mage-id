components/loaders/css/ is the ONLY place besides components/ui/motion.ts where `animationKeyframes` may appear (scripts/validate-motion.ts rule 4). Every file here registers its keyframes through StyleSheet.create (react-native-web silently drops an inline keyframe object), writes every duration and delay as a string ('1400ms', never a bare number, which RN-web turns into px), uses animationFillMode 'backwards' (never 'both', whose retained transform re-roots position: fixed descendants), animates transform and opacity only (scripts/validate-level.ts rule D), and restarts an animation by switching to a byte-different keyframe twin rather than re-setting the same name.
