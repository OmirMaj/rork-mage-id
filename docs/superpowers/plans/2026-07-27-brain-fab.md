# MAGE ID Brain FAB (Workstream C) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Replace the five scattered "AI" doors (two home cards, the 3-FAB HomeFabStack, standalone AICopilot FABs on schedule/estimate, and Cmd+K search) with **one global, search-first Brain floating button** that opens a unified surface: search + ask + voice + "what needs you now."

**Architecture:** A global `BrainFab` (mounted once in `app/_layout.tsx`) opens the existing search-first surface via `SearchContext.openSearch()`. That surface (`UniversalSearch`) is enriched to lead with the Brain Watch attention feed and Ask / Voice rows, so it becomes the single command center. Once the surface covers every capability, the old doors are removed.

**Tech Stack:** React Native + Expo Router, `SearchContext` (`@nkzw/create-context-hook`), `useBrainWatch`, lucide-react-native.

**Blast radius note:** High. Sequenced into slices so each leaves a working app. Slices 2–3 (removals) benefit from on-device verification since the affected screens are behind login.
